01

Nền tảng

ENV là gì?

Khái niệm

Environment variable là cặp TÊN=GIÁ_TRỊ được đưa vào tiến trình khi ứng dụng khởi động. Code giữ nguyên giữa local, test và production; chỉ cấu hình thay đổi.

Vì sao dùng?

Tách secret khỏi source code, thay endpoint theo môi trường, bật/tắt tính năng và triển khai cùng một bản build ở nhiều nơi.

ENV không phải database

ENV phù hợp với cấu hình ít thay đổi khi chạy. Giá sách, nội dung, trạng thái đơn hàng và quyền người dùng phải nằm trong database.

Public

Có thể xuất hiện trong browser, ví dụ URL API.

Internal

Chỉ backend dùng nhưng không phải mật khẩu.

Secret

Credential/chữ ký; lộ là phải thu hồi và tạo lại.

Generated

Secret do mình tự sinh ngẫu nhiên.

04

Deep dive

PayOS xử lý thanh toán ra sao?

Điểm quan trọng: returnUrl chỉ giúp giao diện điều hướng. Backend chỉ cấp Ebook/Premium sau khi webhook hợp lệ hoặc đã chủ động đối soát trạng thái với PayOS.
  1. 01

    Tạo đơn nội bộ

    Backend tự tính tổng tiền từ database, tạo Order và Payment trạng thái PENDING. Không tin giá tiền từ frontend.

  2. 02

    Tạo payment link

    PayOSService dùng Client ID + API Key để gọi PayOS; Checksum Key ký dữ liệu gồm amount, orderCode, description, returnUrl và cancelUrl.

  3. 03

    Khách quét VietQR

    Backend trả checkoutUrl; frontend chuyển khách sang trang PayOS. Secret không bao giờ đi xuống browser.

  4. 04

    Hai tín hiệu quay về

    Browser về returnUrl để hiển thị kết quả. Đồng thời PayOS gọi PAYOS_WEBHOOK_URL trực tiếp tới backend.

  5. 05

    Xác minh và đối chiếu

    Backend verify signature bằng Checksum Key, rồi kiểm tra orderCode, amount, paymentLinkId và trạng thái hiện tại.

  6. 06

    Hoàn tất idempotent

    Trong transaction: đổi Payment sang PAID, đổi Order sang PAID, cấp ReadingRight/Premium đúng một lần và trả HTTP 2xx.

Khởi tạo PayOS ở backend
const payOS = new PayOS({
  clientId: config.getOrThrow('PAYOS_CLIENT_ID'),
  apiKey: config.getOrThrow('PAYOS_API_KEY'),
  checksumKey: config.getOrThrow('PAYOS_CHECKSUM_KEY'),
});
Xử lý webhook — pseudo code
const data = payOS.webhooks.verify(payload);
const payment = await findByOrderCode(data.orderCode);

assert(payment.amount === data.amount);
if (payment.status === 'PAID') return { ok: true };

await completePaymentInTransaction(payment, data);

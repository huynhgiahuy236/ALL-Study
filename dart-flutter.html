01

Label — widget Text

Flutter không có widget tên "Label" riêng — dùng Text để hiển thị chữ tĩnh (giống <label> hay TextView).

Cú pháp khai báo

Text(
  'Nội dung hiển thị',
  style: TextStyle(
    fontSize: 16,
    fontWeight: FontWeight.bold,
    color: Colors.black87,
  ),
)
Thuộc tính Ý nghĩa
style Định dạng font, size, màu, độ đậm
textAlign Căn lề: left / center / right
overflow Xử lý khi chữ tràn (ellipsis…)
maxLines Giới hạn số dòng hiển thị
Cách hoạt động: Text là widget "stateless" thuần hiển thị — không tự thay đổi, muốn đổi nội dung phải bọc trong StatefulWidget và gọi setState.
02

Checkbox

Ô vuông tick chọn/bỏ chọn một giá trị boolean (true/false).

Cú pháp khai báo

Checkbox(
  value: isChecked,             // bool: true / false
  activeColor: Colors.orange,
  onChanged: (bool? newValue) {
    setState(() {
      isChecked = newValue!;
    });
  },
)
Checkbox bắt buộc phải nằm trong StatefulWidget vì value cần thay đổi được theo thời gian.
03

Radio

Chọn một trong nhiều lựa chọn — các Radio cùng nhóm chia sẻ một biến groupValue.

Cú pháp khai báo

Radio<int>(
  value: 1,                 // giá trị đại diện của lựa chọn này
  groupValue: selectedValue,   // giá trị đang được chọn trong nhóm
  onChanged: (int? val) {
    setState(() => selectedValue = val);
  },
)
Cách hoạt động: khi value == groupValue → radio đó hiển thị đã chọn. Đổi groupValue sẽ tự đổi radio nào được tick.
04

Button

Flutter có nhiều loại: ElevatedButton (nổi khối), TextButton (phẳng), OutlinedButton (viền), IconButton (chỉ icon).

Cú pháp khai báo

ElevatedButton(
  onPressed: () {
    // hành động khi bấm
  },
  style: ElevatedButton.styleFrom(
    backgroundColor: Colors.red,
  ),
  child: Text('Bấm vào đây'),
)
IconButton(
  icon: Icon(Icons.favorite),
  onPressed: () {},
)
Nếu onPressed: null → nút tự động chuyển sang trạng thái "disabled" (mờ, không bấm được).
05

Slider

Thanh trượt chọn giá trị số trong một khoảng (min–max).

Cú pháp khai báo

Slider(
  value: currentValue,      // double
  min: 0,
  max: 100,
  divisions: 10,           // số nấc chia (tuỳ chọn)
  label: currentValue.round().toString(),
  onChanged: (double val) {
    setState(() => currentValue = val);
  },
)
06

Image & Icon

Hiển thị hình ảnh (asset, network, file) hoặc icon có sẵn từ bộ Material Icons.

Cú pháp khai báo

// Ảnh từ thư mục assets
Image.asset('assets/images/logo.png', width: 100)

// Ảnh từ internet
Image.network('https://example.com/pic.jpg')

// Icon
Icon(Icons.star, color: Colors.amber, size: 28)
Nhớ khai báo asset trong pubspec.yaml (mục flutter: assets:) thì Image.asset mới nhận diện được file.
07

Row

Sắp xếp các widget con theo hàng ngang.

Cú pháp khai báo

Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween, // trục ngang
  crossAxisAlignment: CrossAxisAlignment.center,      // trục dọc
  children: [
    Icon(Icons.home),
    Text('Trang chủ'),
    Icon(Icons.arrow_forward),
  ],
)
mainAxis của Row là ngang, crossAxis là dọc — ngược lại hoàn toàn với Column.
08

Column

Sắp xếp các widget con theo hàng dọc.

Cú pháp khai báo

Column(
  mainAxisAlignment: MainAxisAlignment.center,   // trục dọc
  crossAxisAlignment: CrossAxisAlignment.start,  // trục ngang
  children: [
    Text('Tiêu đề'),
    SizedBox(height: 8),
    Text('Mô tả bên dưới'),
  ],
)
Dùng SizedBox(height:...) giữa các phần tử để tạo khoảng cách thay vì margin.

09

Chức năng: Checkbox

Toggle giá trị bool và cập nhật UI ngay lập tức qua setState.

class MyCheckbox extends StatefulWidget {
  @override
  State createState() => _MyCheckboxState();
}

class _MyCheckboxState extends State<MyCheckbox> {
  bool agree = false;

  @override
  Widget build(BuildContext context) {
    return Row(children: [
      Checkbox(
        value: agree,
        onChanged: (v) => setState(() => agree = v!),
      ),
      Text('Tôi đồng ý điều khoản'),
    ]);
  }
}
Bản chất: mỗi lần tick → onChanged trả về giá trị mới → setState() báo Flutter "vẽ lại" widget với state mới.
10

Chức năng: Button

onPressed nhận một hàm callback — chạy logic bất kỳ khi người dùng bấm.

int counter = 0;

ElevatedButton(
  onPressed: () {
    setState(() => counter++);
  },
  child: Text('Đếm: $counter'),
)
Có thể dùng async trong onPressed để gọi API rồi setState khi có kết quả trả về.
11

Chức năng: Radio Group

Nhiều Radio dùng chung 1 biến groupValue để đảm bảo chỉ 1 lựa chọn được chọn tại một thời điểm.

String? gioiTinh = 'nam';

Column(children: [
  ListTile(
    title: Text('Nam'),
    leading: Radio<String>(
      value: 'nam', groupValue: gioiTinh,
      onChanged: (v) => setState(() => gioiTinh = v),
    ),
  ),
  ListTile(
    title: Text('Nữ'),
    leading: Radio<String>(
      value: 'nu', groupValue: gioiTinh,
      onChanged: (v) => setState(() => gioiTinh = v),
    ),
  ),
])
12

Chức năng: ComboBox — DropdownButton

Flutter gọi combobox là DropdownButton: bấm vào mở danh sách, chọn 1 item.

String selected = 'HCM';
final cities = ['HCM', 'Hà Nội', 'Đà Nẵng'];

DropdownButton<String>(
  value: selected,
  items: cities.map((c) {
    return DropdownMenuItem(value: c, child: Text(c));
  }).toList(),
  onChanged: (v) => setState(() => selected = v!),
)
items phải sinh từ danh sách bằng .map() rồi .toList() — mỗi phần tử là 1 DropdownMenuItem.
13

Chức năng: Kéo thả — Draggable / DragTarget

Draggable bọc widget có thể kéo đi; DragTarget là vùng nhận khi thả vào.

Draggable<String>(
  data: 'item-01',           // dữ liệu mang theo khi kéo
  feedback: Icon(Icons.star, size: 40),   // hiển thị lúc đang kéo
  childWhenDragging: Opacity(opacity: 0.3, child: Icon(Icons.star)),
  child: Icon(Icons.star, size: 40),  // hiển thị bình thường
)

DragTarget<String>(
  onAccept: (data) {
    // xử lý khi thả 'data' vào đây
    setState(() => droppedItem = data);
  },
  builder: (context, candidateData, rejectedData) {
    return Container(
      width: 100, height: 100,
      color: Colors.grey[300],
      child: Center(child: Text('Thả vào đây')),
    );
  },
)
Luồng: Draggable phát ra "data" khi bắt đầu kéo → DragTarget theo dõi vị trí thả → nếu thả trúng vùng, gọi onAccept(data).
14

Chức năng: Slider hoạt động

onChanged bắn liên tục khi kéo → thường dùng để hiển thị giá trị realtime (âm lượng, độ sáng...).

double volume = 50;

Column(children: [
  Text('Âm lượng: ${volume.round()}'),
  Slider(
    value: volume, min: 0, max: 100,
    onChanged: (v) => setState(() => volume = v),
  ),
])
15

Chức năng: Scroll & Dropdown menu

Khi nội dung dài hơn màn hình, bọc bằng SingleChildScrollView hoặc dùng ListView (tự scroll sẵn).

SingleChildScrollView(
  child: Column(
    children: List.generate(20, (i) => Text('Dòng số $i')),
  ),
)

Dropdown menu dạng nút bấm mở menu — PopupMenuButton

PopupMenuButton<String>(
  onSelected: (value) {
    // xử lý khi chọn 1 mục trong menu
  },
  itemBuilder: (context) => [
    PopupMenuItem(value: 'edit', child: Text('Sửa')),
    PopupMenuItem(value: 'delete', child: Text('Xoá')),
  ],
)
DropdownButton (mục 12) dùng để chọn 1 giá trị dữ liệu; PopupMenuButton dùng để chọn 1 hành động — khác nhau về mục đích dù giao diện tương tự.

2.Kiến trúc dự án

Widget điều hướng dùng chung (AppBottomNavBar) — tách riêng để HomeScreen gọn.

screens/

Các màn hình danh mục. Chỉ hiển thị danh sách thẻ bài tập, không chứa logic bài tập.

Widget tái sử dụng toàn app: ExerciseCard, ExerciseLauncher (và sau này CustomInputField…).

exercises/

Mỗi bài tập là 1 file widget độc lập, gom theo buổi học / chủ đề.

4 nguyên tắc vàng
1. main.dart là entry point duy nhất. Flutter chỉ chạy 1 hàm main(). Nếu file bài tập cũng có main() + runApp(), bạn sẽ dễ chạy nhầm file, app "mất" bottom navigation, và khi nộp bài project không nhất quán. Một entry point = một luồng khởi động duy nhất, dễ debug.
2. Widget bài tập KHÔNG được gọi runApp(). runApp() gắn widget làm gốc của cả ứng dụng. Widget bài tập chỉ là một "trang" được mở bằng Navigator.push — nó phải trả về UI từ build() để có thể cắm vào bất kỳ đâu: TabBarView, route mới, hay body của màn hình khác. Đó chính là tính tái sử dụng.
3. BottomNavigationBar nối các trang danh mục. HomeScreen giữ _currentIndex (state), body hiển thị _screens[_currentIndex]. Khi bấm tab, onTap gọi setState đổi index → body đổi trang mà không cần push route mới.
4. ExerciseLauncher + ExerciseCard giúp dự án mở rộng vô hạn. Mỗi category screen chỉ cần khai báo 1 danh sách ExerciseItem(title, subtitle, icon, page). ExerciseLauncher tự render ListView các ExerciseCard và tự xử lý Navigator.push. Thêm bài mới = thêm 1 phần tử vào list. Không sửa UI, không viết lại navigation.

  State<HomeScreen> createState() => _HomeScreenState();

class _HomeScreenState extends State<HomeScreen> {
  int _currentIndex = 0;

  final List<Widget> _screens = const [
    MidtermScreen(),
    Buoi2Screen(),
    CalculatorScreen(),
    ShapeCalculatorScreen(),
  ];

  final List<String> _titles = const [
    'Midterm',
    'Buổi 2',
    'Calculator',
    'Shape Calculator',
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text(_titles[_currentIndex]),
        centerTitle: true,
      ),
      body: _screens[_currentIndex],
      bottomNavigationBar: AppBottomNavBar(
        currentIndex: _currentIndex,
        onTap: (i) => setState(() => _currentIndex = i),

}

  • _titles — tiêu đề AppBar đổi theo tab, cùng thứ tự với _screens.
  • body: _screens[_currentIndex] — đổi index là đổi trang, không cần push route.
  • onTap: (i) => setState(...) — navbar báo index mới → setState vẽ lại UI.

4) AppBottomNavBar

lib/navigation/bottom_navbar.dart
Code 
import 'package:flutter/material.dart';

class AppBottomNavBar extends StatelessWidget {
  final int currentIndex;
  final ValueChanged<int> onTap;

  const AppBottomNavBar({
    super.key,
    required this.currentIndex,
    required this.onTap,
  });

  @override
  Widget build(BuildContext context) {
    return BottomNavigationBar(
      currentIndex: currentIndex,
      onTap: onTap,
      type: BottomNavigationBarType.fixed,
      selectedItemColor: Colors.teal,
      unselectedItemColor: Colors.grey,
      items: const [
        BottomNavigationBarItem(
            icon: Icon(Icons.school), label: 'Midterm'),
        BottomNavigationBarItem(
            icon: Icon(Icons.menu_book), label: 'Buổi 2'),
        BottomNavigationBarItem(
            icon: Icon(Icons.calculate), label: 'Calc'),
        BottomNavigationBarItem(
            icon: Icon(Icons.category), label: 'Shape'),
      ],
    );
  }
}
Giải thích
  • Navbar là StatelessWidget: không tự giữ index mà nhận từ cha (currentIndex) và báo lên cha qua callback onTap. Đây là pattern "state ở cha, con chỉ hiển thị".
  • ValueChanged<int> = hàm nhận 1 tham số int, viết gọn của void Function(int).
  • type: fixed — bắt buộc khi có ≥ 4 item, nếu không item sẽ trôi/ẩn label.
  • Muốn thêm tab: thêm 1 BottomNavigationBarItem tại đây + 1 screen + 1 title ở HomeScreen.

5) ExerciseCard — thẻ bài tập

import 'package:flutter/material.dart';

class ExerciseCard extends StatelessWidget {
  final String title;
  final String subtitle;
  final IconData icon;
  final VoidCallback onTap;

  const ExerciseCard({
    super.key,
    required this.title,
    required this.subtitle,
    required this.icon,
    required this.onTap,
  });

  @override
  Widget build(BuildContext context) {
    return Card(
      margin: const EdgeInsets.symmetric(
          horizontal: 12, vertical: 6),
      child: ListTile(
        leading: CircleAvatar(child: Icon(icon)),
        title: Text(title,
            style: const TextStyle(
                fontWeight: FontWeight.bold)),
        subtitle: Text(subtitle),
        trailing: const Icon(Icons.chevron_right),
        onTap: onTap,
      ),
    );
  }
}
Giải thích
  • Gói Card + ListTile thành 1 widget: mọi thẻ bài tập trong app đều đồng bộ giao diện.
  • 4 thuộc tính final + constructor required: buộc nơi gọi truyền đủ dữ liệu.
  • VoidCallback = hàm không tham số, không trả về — dùng cho sự kiện chạm.
  • onTap được chuyển thẳng vào ListTile.onTap — thẻ không tự quyết định mở gì, nơi gọi quyết định.

6) ExerciseLauncher + ExerciseItem

lib/widgets/exercise_launcher.dart
Code 
import 'package:flutter/material.dart';
import 'exercise_card.dart';

/// Mô tả 1 bài tập: hiển thị gì + mở trang nào
class ExerciseItem {
  final String title;
  final String subtitle;
  final IconData icon;
  final Widget page;

  const ExerciseItem({
    required this.title,
    required this.subtitle,
    required this.icon,
    required this.page,
  });
}

/// Nhận list bài tập, render ListView các ExerciseCard
class ExerciseLauncher extends StatelessWidget {
  final List<ExerciseItem> items;

  const ExerciseLauncher({super.key, required this.items});

  @override
  Widget build(BuildContext context) {
    return ListView.builder(
      padding: const EdgeInsets.symmetric(vertical: 8),
      itemCount: items.length,
      itemBuilder: (context, index) {
        final item = items[index];
        return ExerciseCard(
          title: item.title,
          subtitle: item.subtitle,
          icon: item.icon,
          onTap: () {
            Navigator.push(
              context,
              MaterialPageRoute(builder: (_) => item.page),
            );
          },
        );
      },
    );
  }
}
Giải thích
  • ExerciseItem là class dữ liệu thuần (không phải widget): mô tả tiêu đề, mô tả, icon và trang cần mở.
  • ListView.builder chỉ build item khi cuộn tới → hiệu quả với danh sách dài.
  • Navigator.push + MaterialPageRoute — mở widget bài tập như một trang mới, tự có nút back.
  • builder: (_) => item.page — dấu _ nghĩa là "không dùng context này".
  • Đây là lý do widget bài tập không cần main()/runApp(): nó chỉ được push lên làm một route.

4.Category Screens — 4 trang danh mục

Cả 4 màn hình có cùng một khuôn: StatelessWidget trả về ExerciseLauncher(items: [...]). Không logic, không state — chỉ là "bảng chỉ mục" của các bài tập. Học thuộc khuôn này 1 lần là viết được cả 4.

Cách ExerciseItem hoạt động trong màn hình danh mục: mỗi ExerciseItem khai báo sẵn page (widget bài tập). Khi người dùng chạm thẻ, ExerciseLauncher gọi Navigator.push(context, MaterialPageRoute(builder: (_) => item.page)) — Flutter đẩy trang bài tập lên trên HomeScreen, AppBar của trang bài tập tự có nút back để quay lại.

Code 
import 'package:flutter/material.dart';
import 'calculator_text_button.dart';

class CalculatorDemo extends StatefulWidget {
  const CalculatorDemo({super.key});

  @override
  State<CalculatorDemo> createState() =>
      _CalculatorDemoState();
}

class _CalculatorDemoState extends State<CalculatorDemo> {
  final TextEditingController _aCtrl =
      TextEditingController();
  final TextEditingController _bCtrl =
      TextEditingController();
  String _result = '';

  @override
  void dispose() {
    _aCtrl.dispose();
    _bCtrl.dispose();
    super.dispose();
  }

  void _calc(String op) {
    final double? a = double.tryParse(_aCtrl.text);
    final double? b = double.tryParse(_bCtrl.text);
    if (a == null || b == null) {
      setState(() => _result = 'Vui lòng nhập số hợp lệ');
      return;
    }
    double r = 0;
    switch (op) {
      case '+': r = a + b; break;
      case '-': r = a - b; break;
      case 'x': r = a * b; break;
      case '/':
        if (b == 0) {
          setState(() => _result = 'Không chia được cho 0');
          return;
        }
        r = a / b;
    }
    setState(() =>
        _result = 'Kết quả: ${r.toStringAsFixed(2)}');
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Calculator')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          children: [
            TextField(
              controller: _aCtrl,
              keyboardType: TextInputType.number,
              decoration: const InputDecoration(
                  labelText: 'Số thứ nhất',
                  border: OutlineInputBorder()),
            ),
            const SizedBox(height: 12),
            TextField(
              controller: _bCtrl,
              keyboardType: TextInputType.number,
              decoration: const InputDecoration(
                  labelText: 'Số thứ hai',
                  border: OutlineInputBorder()),
            ),
            const SizedBox(height: 16),
            Row(
              children: [
                Expanded(
                    child: CalculatorTextButton(
                        text: '+',
                        onPressed: () => _calc('+'))),
                const SizedBox(width: 8),
                Expanded(
                    child: CalculatorTextButton(
                        text: '−',
                        onPressed: () => _calc('-'))),
                const SizedBox(width: 8),
                Expanded(
                    child: CalculatorTextButton(
                        text: '×',
                        onPressed: () => _calc('x'))),
                const SizedBox(width: 8),
                Expanded(
                    child: CalculatorTextButton(
                        text: '÷',
                        color: Colors.orange,
                        onPressed: () => _calc('/'))),
              ],
            ),
            const SizedBox(height: 20),
            Text(_result,
                style: const TextStyle(
                    fontSize: 20,
                    fontWeight: FontWeight.bold)),
          ],
        ),
      ),
    );
  }
}

E. TriangleCalculatorWidget — Heron + validate

  • Công dụng: Nhập 3 cạnh → kiểm tra bất đẳng thức tam giác → chu vi + diện tích Heron; báo lỗi nếu 3 cạnh không hợp lệ.
  • Điểm mới: sqrt() từ dart:math, logic validate nhiều điều kiện.
Code 
import 'dart:math';
import 'package:flutter/material.dart';
import '../../widgets/page_wrapper.dart';
import '../../widgets/custom_input_field.dart';
import '../../widgets/custom_primary_button.dart';

class TriangleCalculatorWidget extends StatefulWidget {
  const TriangleCalculatorWidget({super.key});

  @override
  State<TriangleCalculatorWidget> createState() =>
      _TriangleCalculatorWidgetState();
}

class _TriangleCalculatorWidgetState
    extends State<TriangleCalculatorWidget> {
  final _aCtrl = TextEditingController();
  final _bCtrl = TextEditingController();
  final _cCtrl = TextEditingController();
  String _result = '';
  bool _isError = false;

  @override
  void dispose() {
    _aCtrl.dispose();
    _bCtrl.dispose();
    _cCtrl.dispose();
    super.dispose();
  }

  void _calculate() {
    final double? a = double.tryParse(_aCtrl.text);
    final double? b = double.tryParse(_bCtrl.text);
    final double? c = double.tryParse(_cCtrl.text);

    if (a == null || b == null || c == null ||
        a <= 0 || b <= 0 || c <= 0) {
      setState(() {
        _isError = true;
        _result = 'Vui lòng nhập 3 số dương';
      });
      return;
    }
    // Bất đẳng thức tam giác
    if (a + b <= c || a + c <= b || b + c <= a) {
      setState(() {
        _isError = true;
        _result = '3 cạnh này không tạo thành tam giác!';
      });
      return;
    }
    final double p = a + b + c;      // chu vi
    final double s = p / 2;          // nửa chu vi
    final double area =
        sqrt(s * (s - a) * (s - b) * (s - c)); // Heron
    setState(() {
      _isError = false;
      _result =
          'Chu vi: ${p.toStringAsFixed(2)}\n'
          'Diện tích: ${area.toStringAsFixed(2)}';
    });
  }

  @override
  Widget build(BuildContext context) {
    return PageWrapper(
      title: 'Tam giác (Heron)',
      body: ListView(
        children: [
          CustomInputField(
              controller: _aCtrl,
              label: 'Cạnh a',
              keyboardType: TextInputType.number),
          CustomInputField(
              controller: _bCtrl,
              label: 'Cạnh b',
              keyboardType: TextInputType.number),
          CustomInputField(
              controller: _cCtrl,
              label: 'Cạnh c',
              keyboardType: TextInputType.number),
          CustomPrimaryButton(
              text: 'Tính',
              icon: Icons.calculate,
              onPressed: _calculate),
          const SizedBox(height: 16),
          Center(
            child: Text(
              _result,
              textAlign: TextAlign.center,
              style: TextStyle(
                fontSize: 18,
                fontWeight: FontWeight.bold,
                color: _isError
                    ? Colors.red
                    : Colors.teal,
              ),
            ),
          ),
        ],
      ),
    );
  }
}

9.Lỗi thi thường gặp & cách sửa

1. Nhiều hàm main()Copy file demo có sẵn main() vào project → chạy nhầm entry point, app mất bottom nav. Sửa: xoá mọi main() ngoài lib/main.dart; file bài tập chỉ giữ class widget.
2. Gọi runApp() trong widget bài tậpWidget trở thành "app riêng", không push mở được, không quay lại được. Sửa: widget chỉ return UI trong build(); runApp duy nhất ở main.dart.
3. Quên importError: 'StudentInfoForm' isn't defined. Sửa: thêm dòng import file chứa class đó; để ý đường dẫn tương đối ../ đúng số cấp thư mục.
4. Trùng tên class2 file cùng khai báo CustomButton → lỗi "defined in both libraries". Sửa: đặt tên có ngữ cảnh (ShapeActionButton, CalculatorTextButton) — xem Recipe 5.
5. Không dispose TextEditingControllerRò rỉ bộ nhớ, bị trừ điểm code sạch. Sửa: trong State thêm @override void dispose() { _ctrl.dispose(); super.dispose(); }
6. Dùng sai BuildContextGọi Navigator.push(context) hoặc ScaffoldMessenger.of(context) với context phía trên MaterialApp/Scaffold → "Navigator operation requested with a context...". Sửa: dùng context của build() bên trong cây MaterialApp; trong kiến trúc này mọi widget bài tập đều an toàn vì MaterialApp nằm ở app.dart.
7. Thiếu constCảnh báo prefer_const_constructors tràn màn hình, mất điểm lint. Sửa: thêm const cho widget không đổi: const Text(…), const SizedBox(…), constructor const A({super.key}).
8. Overflow trong Row/ColumnSọc vàng-đen "BOTTOM OVERFLOWED BY … PIXELS". Sửa: bọc phần co giãn bằng Expanded/Flexible; thay Column bằng ListView khi form dài; Text dài thêm overflow: TextOverflow.ellipsis.
9. Bấm nút mà UI không đổiĐã gán _result = ... nhưng quên bọc trong setState → giá trị đổi mà màn hình đứng im. Sửa: mọi thay đổi state phải nằm trong setState(() {...}) của StatefulWidget.
10. BottomNavigationBar index out of rangeThêm tab vào navbar nhưng quên thêm trang vào _screens (hoặc ngược lại). Sửa: kiểm tra 3 danh sách _screens, _titles, items luôn bằng nhau về số lượng và thứ tự (Recipe 2, bước 4).

Luồng kết nối đầy đủ
  1. main() gọi runApp(const App()).
  2. App dựng MaterialApp + theme, mở HomeScreen.
  3. HomeScreen giữ _currentIndex; bấm tab Exam trên AppBottomNavBar → setState → body = ExamScreen.
  4. ExamScreen chỉ khai báo 3 ExerciseItem; ExerciseLauncher vẽ 3 thẻ.
  5. Chạm thẻ → Navigator.push mở widget bài tập (bọc trong PageWrapper, tự có nút back).
  6. Trong form/calculator: CustomInputField đọc dữ liệu qua controller → nút CustomPrimaryButton gọi hàm tính → setState hiện kết quả (StudentInfoCard hoặc Text).
Checklist trước khi nộp bài:
  • Chỉ 1 main(), 1 runApp() ✔
  • 3 danh sách nav bằng nhau ✔
  • Mọi controller có dispose() ✔
  • Input được validate (tryParse, số dương) ✔
  • Không warning const, không overflow ✔

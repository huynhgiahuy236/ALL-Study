CAPSTONEBOOK DEPLOYMENT GUIDE
============================

Mở file index.html bằng Chrome hoặc Edge. Bộ tài liệu chạy offline, không cần npm hay web server.

Cấu trúc:
- index.html: nội dung hướng dẫn
- styles.css: giao diện responsive, dark mode và bản in
- script.js: tìm kiếm, copy lệnh, lightbox ảnh, checklist và tiến độ đọc
- assets/images/: ảnh chụp từ quá trình triển khai

Lưu ý bảo mật:
- Ảnh được giữ nguyên để đối chiếu. Hãy che Account ID, IP, Invoke URL và dữ liệu định danh trước khi chia sẻ công khai.
- Không thêm .env, file .pem, MongoDB URI, JWT secret hoặc PayOS keys vào bộ tài liệu.

01 · Trước khi tạo tài nguyên

Hiểu đúng Free Plan và chi phí

01

Free Plan

Kết thúc sau 6 tháng hoặc khi hết credit, tùy điều kiện nào đến trước. AWS đóng tài khoản Free Plan thay vì cho chạy âm tiền.

02

AWS Credit

Credit có hạn riêng. EC2, IPv4 và dịch vụ đủ điều kiện sẽ tiêu thụ credit. Theo dõi mục Billing → Credits.

03

Domain

Đăng ký domain Route 53 không dùng được promotional credit; tiền domain tính vào phương thức thanh toán. Test thì chưa cần mua.

Ước tính: EC2 t3.micro + một Public IPv4 + 8 GiB EBS có thể tiêu thụ khoảng 16–17 USD/tháng tùy vùng và lưu lượng. Luôn xem Billing thực tế.
02 · Nền tảng AWS

Tài khoản, Budget, MFA và Region

  1. Tạo AWS account

    Chọn Free Plan, xác minh email/điện thoại và phương thức thanh toán. Không gửi OTP hay thông tin thẻ cho người khác.

  2. Chuyển Region

    Chọn Asia Pacific (Singapore) · ap-southeast-1. Billing hiển thị Global là bình thường.

  3. Tạo Budget

    Cost budget 1 USD/tháng; cảnh báo Actual 80% và Forecasted 100%. Budget có thể báo dù credit đang bù chi phí.

  4. Bật MFA

    Security credentials → Assign MFA device → Authenticator app. Không chụp QR MFA.

03 · Database

Tạo database bookstore trên Atlas

  1. Không xóa database cũ

    Database booking thuộc dự án khác. Tạo database mới bookstore.

  2. Collection đầu tiên

    Data Explorer → Create Database → database bookstore, collection books.

  3. Database User

    Dùng user trong Security → Database Access, không dùng email/mật khẩu đăng nhập trang Atlas.

  4. Network Access

    Thêm Elastic IP của EC2 theo dạng IP_THẬT/32.

DATABASE_URL=mongodb+srv://DB_USERNAME:DB_PASSWORD@cluster0.example.mongodb.net/bookstore?retryWrites=true&w=majority&appName=Cluster0
Không lộ secret: URI thật chỉ nằm trong .env backend. Nếu mật khẩu chứa @ : / # %, phải URL-encode hoặc đặt mật khẩu chữ/số đủ mạnh.

05 · IP cố định

Allocate và Associate Elastic IP

  1. Allocate

    EC2 → Elastic IP addresses → Allocate. Giữ Amazon's pool và border group ap-southeast-1.

  2. Associate ngay

    Actions → Associate Elastic IP → chọn instance CapstoneBook. IP chưa gắn vẫn bị tính phí.

  3. Dùng đúng nơi

    SSH dùng ubuntu@IP; Atlas Network Access dùng IP/32. Không nhập nguyên chữ ELASTIC_IP.

06 · Truy cập máy ảo

SSH từ Windows

Mở Command Prompt trong thư mục có file .pem và dùng IP số thật:

ssh -i "E:\bookstore-aws-key.pem" ubuntu@IP_ELASTIC_THẬT

Nếu báo “bad permissions”

icacls "E:\bookstore-aws-key.pem" /inheritance:r
icacls "E:\bookstore-aws-key.pem" /remove "NT AUTHORITY\Authenticated Users"
icacls "E:\bookstore-aws-key.pem" /remove "BUILTIN\Users"
icacls "E:\bookstore-aws-key.pem" /grant:r "%USERNAME%:(R)"
Không nhập placeholder: lỗi Could not resolve hostname public_dns hoặc elastic_ip xảy ra vì nhập nguyên chữ minh họa. Phải thay bằng DNS/IP thật trong EC2 Details.

08 · Cấu hình backend

.env production trên EC2

Tạo hai JWT secret bằng openssl rand -hex 32, rồi tạo ~/book/.env. Giá trị dưới đây chỉ là mẫu:

NODE_ENV=production
PORT=4000
TZ=Asia/Ho_Chi_Minh

CLIENT_URL=https://TEN-DU-AN.vercel.app
BACKEND_URL=https://API_ID.execute-api.ap-southeast-1.amazonaws.com

DATABASE_URL=mongodb+srv://DB_USER:DB_PASSWORD@CLUSTER/bookstore?retryWrites=true&w=majority

JWT_ACCESS_SECRET=SECRET_1
JWT_REFRESH_SECRET=SECRET_2
JWT_ACCESS_EXPIRES_IN=15m
JWT_REFRESH_EXPIRES_IN=30d

PAYOS_CLIENT_ID=...
PAYOS_API_KEY=...
PAYOS_CHECKSUM_KEY=...
PAYOS_RETURN_URL=https://TEN-DU-AN.vercel.app/payment/payos/success
PAYOS_CANCEL_URL=https://TEN-DU-AN.vercel.app/payment/payos/cancel
PAYOS_WEBHOOK_URL=
PAYOS_PAYMENT_EXPIRES_MINUTES=15
chmod 600 .env
ln -s ../.env backend/.env
npm run start:prod --workspace=@capstonebook/backend
Hai base URL khác nhau: BACKEND_URL chỉ là root API Gateway; NEXT_PUBLIC_API_URL của frontend phải thêm /api/v1.
09 · Chạy ổn định

PM2 giữ tiến trình, Nginx nhận port 80

PM2

sudo npm install -g pm2
cd ~/book
pm2 start npm --name capstonebook-api -- run start:prod --workspace=@capstonebook/backend
pm2 startup
# Chạy chính xác lệnh sudo mà PM2 in ra
pm2 save
pm2 status

/etc/nginx/sites-available/default

server {
    listen 80 default_server;
    listen [::]:80 default_server;
    server_name _;
    client_max_body_size 25M;

    location / {
        proxy_pass http://127.0.0.1:4000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }
}
sudo nginx -t
sudo systemctl restart nginx
sudo systemctl enable nginx
curl -i http://127.0.0.1
HTTP 404 từ Express là tín hiệu tốt nếu root / không có route: header có Server: nginx, X-Powered-By: Express nghĩa là proxy đã chạy xuyên suốt.
10 · HTTPS miễn phí theo lượt dùng

API Gateway proxy đến EC2

  1. Create API → HTTP API

    Không chọn REST API hay WebSocket API. Region Singapore.

  2. Integration HTTP

    Dùng http://PUBLIC_IPV4_DNS của EC2, không dùng private DNS, không thêm /api/v1 hoặc :4000.

  3. Route và Stage

    Route $default, method ANY; Stage $default, Auto-deploy Enabled; Default endpoint Enabled.

  4. Test

    https://INVOKE_URL/api/v1/books phải trả JSON.

11 · Frontend production

Deploy Next.js lên Vercel

  1. Import GitHub repository

    Add New → Project → repo book.

  2. Root Directory

    Chọn frontend; Framework Preset Next.js; Build/Install/Output để mặc định.

  3. Environment Variable

    NEXT_PUBLIC_API_URL=https://INVOKE_URL/api/v1. Chọn Production + Preview; local dùng frontend/.env.local.

  4. Sau khi có domain

    Cập nhật CLIENT_URL, PayOS return/cancel trong EC2 rồi pm2 restart capstonebook-api --update-env.

12 · Thanh toán

PayOS: phần đã có và phần còn lại

Ba khóa bí mật

my.payOS.vn → Kênh thanh toán → chọn kênh → Client ID, API Key, Checksum Key. Chỉ đặt trong backend EC2.

Webhook

PAYOS_WEBHOOK_URL phải là endpoint HTTPS công khai và trả HTTP 2xx. Cần xác định route thật trong controller trước khi điền.

grep -Rni "webhook" backend/src
grep -Rni "setGlobalPrefix" backend/src
Chưa hoàn tất PayOS nếu webhook còn trống. Frontend/backend có thể chạy, nhưng trạng thái thanh toán chưa được xác nhận tự động.

14 · Tra cứu

Lỗi thường gặp và cách xử lý

Could not resolve hostname public_dns / elastic_ip

Bạn đã nhập nguyên placeholder. Thay bằng Public IPv4 DNS hoặc Elastic IP thật. Không thêm dấu <>.

WARNING: UNPROTECTED PRIVATE KEY FILE / bad permissions

Dùng các lệnh icacls trong mục SSH để bỏ quyền Authenticated Users và chỉ cấp quyền Read cho user Windows hiện tại.

EC2 Running nhưng Status check Initializing

Chờ 5–10 phút và refresh. Quá 15 phút: xem System/Instance status check, Ctrl+F5; reboot trước khi nghĩ đến Stop/Start. Không Terminate.

MongoServerError: bad auth

Network đã tới Atlas nhưng Database User/password sai. Reset user trong Database Access, không dùng tài khoản đăng nhập Atlas; kiểm tra URL encoding.

listen directive is not allowed here

Bạn dán block server mới vào trong cấu hình cũ. Xóa toàn bộ file default và giữ đúng một block server rồi chạy sudo nginx -t.

502 Bad Gateway

Nginx không gọi được NestJS. Kiểm tra pm2 status, pm2 logs, port 4000 và proxy_pass http://127.0.0.1:4000.

404 Not Found tại IP gốc

Nếu response là JSON, có Express/CORS headers thì proxy đã đúng; backend chỉ không có route /. Test /api/v1/books.

API Gateway báo URL must be fully-qualified

Dùng http://PUBLIC_IPV4_DNS của EC2 thay vì private DNS hoặc placeholder. Không thêm port 4000.

Vercel HTTPS gọi EC2 HTTP bị chặn

Đây là mixed content. Frontend Vercel phải dùng URL HTTPS của API Gateway trong NEXT_PUBLIC_API_URL.

CORS chỉ cho localhost:3000

Đổi CLIENT_URL sang domain production Vercel rồi restart PM2 với --update-env.

Vercel chạy npm install như Build Command

Tắt Build Command Override hoặc đặt npm run build. Install Command để mặc định.

Lightning CSS thiếu binary Linux

Regenerate sạch root package-lock.json như mục Vercel, kiểm tra lock có lightningcss-linux-x64-gnu, commit rồi push.
